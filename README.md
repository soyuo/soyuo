**서비스를 설계하고 구현하며, 사용자 경험과 운영 환경까지 고민하는 개발자입니다.**

웹·백엔드 개발을 중심으로 CLI, 자동화 도구, 네트워크 및 시스템 개발에 관심을 가지고 있습니다.

기능 구현에 그치지 않고, 유지보수성과 성능, 사용자 경험을 함께 고려합니다.

직접 만들고 운영하며 발견한 문제를 기술적으로 해결하는 과정을 중요하게 생각합니다.
